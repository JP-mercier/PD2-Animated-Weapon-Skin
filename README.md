## 📦 Installation

1. Install **[SuperBLT](https://superblt.znix.xyz/)** and **[BeardLib](https://modworkshop.net/mod/14924)** if you do not already have them.
2. Download this repository (Code → Download ZIP).
3. Extract the folder into:
   `PAYDAY 2/assets/mod_overrides/`
4. Rename the folder to `Inversion Universal` if it is not already named that.
5. Launch PAYDAY 2.

---

## ⚠️ Notes

- This is a `mod_overrides` pack. It applies an animated inversion-style glow to weapons.
